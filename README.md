# Sunwake website

Static marketing, privacy and support website for Sunwake.

Expected GitHub Pages address is https://destroywerk.github.io/sunwake/.

In repository Settings → Pages, set the source to Deploy from a branch, then main and / (root). All site URLs and assets support the /sunwake/ project path.

Preview locally with python3 -m http.server 8766.

The native screenshots show example alarm data and the latest local UI. They are 1320 × 2868 PNG images. The bundled League Gothic font is licensed under the included SIL Open Font License.

Site code sets no cookies and includes no analytics scripts, tracking pixels, remote fonts or contact forms. GitHub Pages processes visitor data under GitHub's privacy statement. Contact links use email.

Tim Green is the working operator identity. The public privacy text uses retention criteria rather than an unconfirmed fixed period. Confirm applicable operator, contact and email-provider details before broad public launch.
